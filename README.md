# Tahseen Ahmed - Portfolio Backend 
 
REST API for Tahseen Ahmed personal portfolio website. 
 
## Tech Stack 
- Node.js + Express 
- MongoDB Atlas + Mongoose 
- JWT Authentication 
- Cloudinary image uploads 
 
## Setup 
1. Clone the repo 
2. Run: npm install 
3. Create .env file with your credentials 
4. Run: npm run dev 
 
## API Routes 
- POST /api/auth/login 
- GET /api/projects 
- GET /api/skills 
- GET /api/profile 
- POST /api/messages
